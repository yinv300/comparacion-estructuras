# Comparación de estructuras de datos
Informe individual de Arreglos Estáticos, Listas Simples y Listas Doblemente Enlazadas.

## Ejecutar
Desde la carpeta del proyecto:

```bash
javac src/Main.java
java -cp src Main
```

El programa utiliza un arreglo int[], una lista simple implementada en código y java.util.LinkedList (doblemente enlazada). Los tiempos son ilustrativos, no pruebas estadísticas rigurosas. El consumo de memoria se compara de forma teórica en el informe.
